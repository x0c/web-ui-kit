# Security Policy

## Scope

`@x0c/tokens` and `@x0c/ui` are pure client-side CSS tokens and React 19 UI primitives/patterns distributed on npmjs.org. Neither package executes telemetry, stores secrets, or contacts external endpoints at runtime (`BrandMark` only renders `logoUrl` strings beginning with `https://`).

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's private vulnerability reporting at `https://github.com/x0c/web-ui-kit/security/advisories/new`. Do not open public issues for unpatched security bugs.
